## 怎么玩

引擎用 `cmd("指令")` 调用。常用指令：
- `cast [饵] [N] [stop=new]` — 甩竿（连钓+自动停）
- `goto [地点id]` — 换钓点（无参数列出所有）
- `dive [N] [stop=new]` — 潜水探索
- `encyclopedia` — 查图鉴
- `inventory` — 查背包
- `shop` — 商店
